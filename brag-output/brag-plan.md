# Brag Plan: Dancing with the SARs — Flood Pulse

## What is this app?
A NASA Space Apps ops desk that separates Atlas demos, a 3D Blue Marble globe, and live ASF/Earthdata sources so radar storytelling stays honest.

## The angle
Not another flood dashboard that fakes live disaster maps. This one names what is illustrative and what is catalog truth — Japan/Brazil demos, dual Earth textures, live Sources — in one coherent desk.

## Hook (first 2-3 seconds)
Dark ops-desk frame + brand: “DANCING WITH THE SARs” / “Read change through radar.”

## Key moments (the middle)
- Atlas: Japan/Brazil · Demo · 30 seconds · NASA EO references
- 3D Globe: Synced map vs Real Blue Marble + white-background checkbox + country hover
- Live Sources: ASF / Earthdata latest windows, separate from overlays
- Honesty beat: flood/fire sectors are teaching seeds, not verified perimeters

## Outro / punchline
“Read change through radar — and keep the story accountable.”

## User flow worth showing
Entry (Atlas country + Demo) → key action (Globe mode switch / white bg) → result (Live Sources honesty).

## Tone
- Preset: polished
- Creative direction: humanized NASA Space Apps walkthrough with male VO
- Interpretation: calm, specific, detail-rich; readable subtitles; no hype

## Format: landscape — 1920x1080
## Duration: 90 seconds (user override of default 15–25s brag window)

## Visual identity (from the project)
- Background: #0a1620 / #07111f
- Accent: #6eb8ae teal; flood #e6c65a; fire #e07040
- Text: #e6eef2 / muted #8fa6b3
- Display font: Space Grotesk (project) / system fallbacks for render
- Strongest visual: 3D Blue Marble globe + Synced | Real Blue Marble toggle
